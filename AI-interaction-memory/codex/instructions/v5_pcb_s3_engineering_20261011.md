## 2. 最重要：各板最大工作功率和电源选择的严格方法

### 2.1 首先制作三板 `LOAD_AND_POWER_BUDGET.csv/.xlsx`，强制一行对应一种器件/功能负载

包含字段至少：`Board`, `Rail`, `Refdes/Qty`, `Device/Function`, `Operating mode`, `Vin min/nom/max`, `Vout`, `I_typ`, `I_max_continuous`, `I_peak`, `t_peak`, `f_sw`, `max active channels`, `standby draw`, `datasheet revision/table/page`, `guaranteed vs typical vs assumption`, `power formula`, `P_max_continuous_W`, `P_peak_W`, `loss_W`, `heat_W`, `confidence`, `source URL`, `open qualification`. 所有器件数量从工作候选净表、原理图位号、各功能模块逐一对账，包括连接器/LED/晶振/电平转换/电源芯片自身消耗，不能只统计主 IC。

器件级功率预算必须区分：
- **最大连续工作消耗**：原厂在适用电压、温度、工作模式、频率等条件下规定/保证的最大 `IDD/ICC/IQ/Iout consumption`；若数据表仅给典型，无保证上限，不得将典型偷换为最大，执行有约束的上界设计。
- **最大输出能力**：例如 TPS54202 的 `2A` 是变换器输出能力，不意味着下游始终消耗2A；TC4427A 的 `1.5A peak` 是脉冲驱动能力，不等于每路稳态1.5A。不得把所有输出芯片的供电能力直接求和作为功耗。
- **瞬态/脉冲峰值**：给出最不利同时切换、电流上升、波形时间和峰值持续时长，供电容/线阻/连接器/eFuse SOA 选型；不得将短脉冲峰值直接当连续热耗。
- **绝对最大额定值**：不得当作正常工作点或功耗计算工作电压；用来核验过压、反灌、故障和瞬态裕量。
- **典型值/无保证值**：保留为补充估算；必须用电路限流、可证明的波形约束、器件工作特性上下界或保守的设计包络补齐，而非凭主观增添 30%。

**计算层级**：`IC 最大实际消耗 → 各负载电源轨最大输出功率 → 转换器损耗及效率最坏界 → 12V/5V 输入最大连续电流 → 保险/eFuse/接头/线束/适配器`。高、低电压轨不能直接把安培数相加；必须在功率域换算，防止重复统计电容充放电已经包含的能量。每板各给 `NORMAL_MAX`、`STARTUP_INRUSH`、`SWITCHING_WORST`、`FAULT_LIMITED` 四个不同工况。

公式示例：
- `P_rail_max = sum(V_rail,max * I_device,max,applicable)`；该模式必须满足同时出现的物理约束，不能无意义叠加互斥工作状态。
- `P_input,max = Σ(P_rail,out,max / η_min_proven) + P_direct,max + P_protection_loss,max`；若没有效率最小保证，分项通过开关/导通损耗和温升建界，或标为 `DESIGN_ENVELOPE_CONDITIONAL`。
- `I_adapter_cont,max = P_input,max / V_adapter,min`；额定容量应覆盖该上限，且产品规定的工作温度/降额/持续负载要求成立。
- `I_peak(t)`、`∫I(t)dt`、`∫I²(t)dt` 分别用于源/滤波电容/保险与脉冲温升；电源本身的过载特性与下游电容浪涌必须协调。
- `Tj = Ta,max + Ploss * θJA_board_estimated` 只是首轮热筛查，计算其在实际铜面积、封装、邻近热源/散热条件下成立的条件；不能仅用厂家 EVM θJA 当最终PCB实测。

**电源选定规则（Codex 自行得出数值和器件）**：
- 中央：固定输入 `5V/3A`，`Pin_budget ≤ 15W` 为绝对额定容量预算，另核验 USB-C 规范下 VBUS 最小值、输入路径损耗、过流与热裕量。若全板最不利工作模型越过15W，**优先优化电源拓扑/减少可证明的无效转换损耗**；若仍无法落入15W，明确 `POWER_INFEASIBLE` 并提交需要修改的约束，不得把3A说成5A或偷偷依赖AX7020供电。禁止假定PC普通Type-C口天然能提供3A；供电口与既有PC/UART接口职责明确分开，若机械上共用，须验证Host Type-C广告、USB数据与电流协商都能满足。
- 上/下阵列：分别计算，原则上保持同构，但若计算不同则按两块中的更严格上界统一额定。根据计算选择 **12V/2A、3A、4A、5A或更高**中的最低合规容量档位（只要能够满足连续+瞬态及温度降额）；不要固定“60W更稳”或“30%一定要加”。若接口为5A额定，持续工作在5A且没有边界裕量时，评估更高额定/低接触阻抗连接器，而不是只加大适配器瓦数。适配器推荐需给出至少一款可查官方规格的实物系列及匹配插头参数；**不要求本轮采购**。
- `TPS26631`、外部12V物理开关、TVS、输入浪涌、外部线长、输入保险应按实际连续上限与故障峰值联合选择，限制并验证输出/驱动的最大电压；`ILIM`、dV/dt、SOA及2×pulse模式不能遗漏。旧1.65kΩ候选无效，必须清除其错误结论；必要时换符合功耗/保护等级的安全器件候选，不以保留旧 eFuse 为最高优先级。
- 任何**理论上无可证明上限**的压电负载或反灌行为，设置可硬件强制的电流/温度/脉冲能量/电压范围，在保证允许工况内按限流约束计算板端最大输入耗电。**报告必须把“计算得到的设计供电上界”和“未证明的器件负载模型”分开**。

### 2.2 TX 计算不得重复或漏算

64路/阵列、128路总数；NU40C10T 最新确认资料中静态电容约2.2nF±20%是用于首轮模型的输入，不等于完整40kHz谐振阻抗。`P_C = N * C_max * (ΔV_max)^2 * f_max` 只适用于充放完全建立、非回收的理想电容模型；必须附上 `R_m,L_m,C_m` 或厂家阻抗/相位等效模型的出处，若无法得到，保留未知并由硬件边界约束。分别列：充放电能量、驱动内部/串阻分摊、交越电流、驱动IQ、压电机电支路损耗、反灌电流、降压供电、输出无效负载及最不利齐相/随机相位边沿。**不允许重复加上已在电容能量中包含的驱动耗散。**

供参考的 S2 理想模型：在 `C=2.2nF, f=40kHz, ΔV=12V` 下每板64路约 `0.811W`，整机128路约 `1.622W`；该值**不是总板功率、不是驱动热耗上界、不是电声功率、不是适配器容量**。Codex 必须另给最终可执行的供电受限工况和选型上界。

## 3. S3 器件级电路设计：必须真正落到原理图连接与真值表

### 3.1 中央板独立 5V/3A Type-C 与 ADC电源

- 明确 **USB-C 5V供电专用/共享数据口**的系统边界与既有 PC→UART→PS→PL 控制链关系。不得误认为 `STUSB4500L` 自动提供数据串口，也不得未经证据认定普通PC USB口可输出3A；必要时保持独立的数据链及明确接口名称。
- 完成：Type-C receptacle/CC Rd或经验证的Type-C控制器/ESD/反接与倒灌保护/过流/浪涌/输入电容/线压降/可选负载开关/电源好指示。高电流触点数和线材额定必须真实核验。
- ADC `AD7606C-16` AVCC工作范围是 4.75–5.25V；**不能把5V USB输入在低压、线损条件下经LDO直接供电就宣称合格**。比较低损稳压路径与升降压路径，选择能在 USB 输入最差合法电压下满足 AVCC、输入功率15W约束、噪声和ADC精度的最简单合规拓扑；给出最低效率和最大电流预算。VDRIVE 独立对应实测待核的 AX7020 IO 电平，不可想当然固定3.3V。
- `AD7606C-16` REGCAP36/39各1µF，REFCAPA/B相联的公共低ESR10µF、REFIN/REFOUT、AVCC每脚去耦与电源稳定顺序逐pin落实，严格依原厂引脚/应用图；每个供电轨端口加允许和故障态复核。
- `INA226` / `TMP117` / `TCA9548A` 的电源、I²C pullups/RESET、保护必须计入此板功耗；提供Type-C负载与中央USB分配的预算表和启动/掉电顺序。

### 3.2 两块12V阵列：常供电逻辑+受控TX功率轨

- 两块均有：12V DC输入、保险/TVS/反接保护、输入eFuse/浪涌控制、独立硬件TX rail切断与泄放、3.3V控制轨、需要时的5V模拟轨、监控/故障锁存、RX AFE及温度/电流传感器。
- `TPS54202` 是**2A额定输出的Buck**，重新按真实轨负载、`Vin min/max`、`fsw min/max`、`VFB min/max`、磁感偏差、峰值限流下限算 L/C/ESR/Isat/Irms/损耗/环路稳定性/瞬态/热；6.8µH和22µH都不得被机械套用。电源3.3V和5.5V/5V需求分别核算；LDO `ADP7118` 200mA容量及压差/功耗必须符合负载。高噪声驱动与RX模拟供电应分隔回流/供电滤波但保持确定的共同参考。
- TX rail 的默认OFF必须从**上电前、控制3.3V掉电、AX7020失电、跨板断线、eFuse故障、信号高阻、看门狗输出释放**各种情况成立。不得用“软件默认关”“SN74LVC595A OE高”代替切断。
- **关键绝对额定风险**：TC4427A 输入引脚不能在自身VDD=0时仍受外部3.3V高电平强驱；同时切断TX轨却保留595控制轨可能反灌/输入过压。提出**具体原厂保证的Ioff隔离/专用buffer供电/先禁能后切电/输入钳位受限网络**并画出真实网络，逐阶段核验 `VIN ≤ VDD + datasheet allowed headroom`，包括输入端断线、漏电、上电时序、瞬态，而不是只写操作顺序。
- `SN74LVC595A` 在 OE禁能时高阻，100k下拉可能无法保证 TC4427A 的 VIL，按数据手册 IOZ+输入漏电算最差阈值及VOH/VIH高态余量；采用能保证全温可用的缓冲/电平接口或更合适阻值并核验负载。确保共时基66MHz串行/锁存到真实芯片引脚符合setup/hold/最小高低电平宽度和连接线条件。
- `TPS3851H33EDRBR` **每阵列1颗**（不是每阵列2颗），RESET/WDO、WDI边沿、MR/SET1/CWD、阈值、低POR的未定义态、非锁存WDO，逐个落实。**保持已提出的独立窗口/过快喂狗安全需求**，优先以最少额外器件完成真正独立的window与锁存/功率门控，比较合并安全功能的高集成度方案，但不更换已批准 TPS3851；从原理图列出新增物理器件和必要性。让安全要求落实而非无限扩充芯片。若发现独立过快窗口本身会增加不适当复杂度，可在问题包说明风险与推荐，但在获正式批准前不得将其删去。
- **真正心跳**必须由已完成的工作/有效的安全服务事务支撑，不可由自由运行定时器假装工作正常；对静止悬浮、待机、启停、掉电、故障、复位的心跳规则提出可在现有RTL协议上实现的合约，主线RTL变更作为单独handoff，不在PCB分支擅改RTL。
- 独立常供电监控、硬件NC急停、过温、UVLO/OVP、过流、看门狗、失电检测→**故障优先锁存/硬件关断/可检验泄放/受控手动重新使能**；分别给出逻辑电源存在/不存在下真实默认栅极电位及失效优先真值表。只选合规且必要的反向阻断架构，不强制无条件叠放多个back-to-back FET，如使用该拓扑须解释不可替代的功能。
- 不能仅根据 `TPS26631` 输出限制保证全部驱动安全；计算源/插座/线/TVS/功率FET/电容并联瞬态、电感寄生、保险响应、电流采样最大压差及本地热点。
- `INA226` 在 ±81.92mV 范围内设计分流电阻，包含容差+故障峰值+Kelvin连接+发热。10mΩ仅是可审候选；最终根据选出的适配器和系统设计上限计算，不机械固定10mΩ。

### 3.3 64TX驱动器件级原理图

每阵列 16×595 + 32×TC4427A + 64×NU40C10T，物理mapping从当前合约复用，32 lanes×4 used 不变。逐lane验证：数据链、锁存时序、OE/RESET、缓冲/断电逻辑、输入默认、驱动输出串阻/ESD/EMI、12V去耦/局部大容量、回流、TVS与探针测试点。NU40C10T 允许连续驱动电压/频率/热与机械安装参数须以确切厂家型号数据（含波形条件）核实；并计算剩余应力与热边界。不同初始相位同时切换作电源设计最坏情况之一。对一个驱动板抽象出1路→4路→16路→64路同构网络，并输出复制核验脚本或位号表，避免128路人工手改造成连接错误。

### 3.4 RX/AFE/ADC链和相位一致性

每阵列 4RX、每阵列 2颗 OPA4192（共8放大器）等现有功能分配需要用完整电路图核验。明确RX型号、静电电容、灵敏度、最坏开路/激励耦合电压、连接线寄生、失电异常输入。完成每路输入限幅/限流及失电不反灌、偏置、放大、滤波、输出驱动、ADC范围/保护、线缆屏蔽与屏蔽终接。把共模范围、相位延时、噪声带宽、抗混叠及40kHz实际数字滤波设置放进设计计算。AD7606C-16 的高带宽并非所有量程保证220kHz、低带宽25kHz不适合直接保持40kHz原幅；须按原厂量程/配置确定。**不强行把未知的RX最大输出写成确定数字**；使用可保证额定的输入钳位网络形成故障保护设计上界。分离本板发射驱动高di/dt与RX前端，给出分区、地回流、时钟干扰和测试点方案。

### 3.5 引脚、外部信号和机械

核对实际 AX7020 Rev3.0 `J10/J11` 80触点、主控完整后缀、Bank VCCO 与真实IO功能；禁止从仍不完整的原 63IO wrapper 推断RESET/SYNC/FAULT已连接。对每个外部信号列：源/接收端电压域、默认电平、方向、Ioff、外部负载、线缆长度、时钟约束、FPGA XDC/RTL状态。软件数字端口修订只生成给主线的接口契约/问题单，不越权改RTL/XDC。66MHz外部链路需按 datasheet 的 tco/tsu/th/clk skew/IBIS包络给出设计预算，不能凭595芯片fmax≥66MHz就宣称线束合格。

明确 5.5×2.5mm 插座与电源插头兼容/中心正/键控/额定电流，四电源地参考和故障回流，RX线不能误插普通网口，I²C多电源掉电Ioff，一次仅激活对应TCA9548A通道。12mm TX pitch、100mm辐射面距、背面器件空间、四角RX声学/散热/固定柱与测试夹具尺寸核对；原生布局尚未布线可提出层叠、分区和规则，不声称已完成SI/EMI认证。

## 4. 无源件必须按位置与极限参数定值，不用锁死厂商品牌

对所有新旧 R/C/L、TVS、磁珠、eFuse阻值、FET栅极、RC超时、ADC输入、AFE滤波、Type-C CC、I²C、电源FB、TX去耦和泄放电阻逐`refdes→网络→功能→参数→公式`审计。默认优先 SMD：0603/0805 为通用小信号首选，功率/脉冲器件按热、耐压、爬电/生产工艺必要时使用1206、2010、贴片功率封装，不能为“全部0603”牺牲可靠性；电感屏蔽型 SMD、稳压电容尽可能X7R/X5R并按DC Bias后的有效容量核算。每一条至少给：

- 电阻：名义/最不利阻值、容差/TCR、平均/脉冲功率/电压系数、封装、是否需要Kelvin/低电感。
- 电容：名义/有效容值、DC偏压和温漂降额、容差、额定电压、ESR/ESL、纹波电流、储能/启动/环路位置、封装。
- 电感：Lmin/Lnom、DCR、I_sat、I_rms、温升、工作频率/磁屏蔽、环路与布局。
- 避免将原B-054 100kΩ、B-061 0Ω、H-020 128下拉等旧条目当成独立新器件；逐实net核对去重。功能块 `BACK_TO_BACK_FET_AND_DRIVER_TBD` 等必须拆为实际芯片/MOS/分立元件/无源/连接器，不得以一行模块占位冒充可采购件。

**每个计算同时记录：datasheet typical / guaranteed min / guaranteed max / engineering constraint，以及计算脚本与输出的commit/hash。** 凡缺原厂有效上限，必须体现约束或限定条件，不能默认为“最大值 = 典型值”。
