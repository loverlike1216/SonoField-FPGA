## 3. 固定系统边界，先找结构错误再给元件值

审查对象为三板：**中央接口/采集 PCB ×1 + 上阵列 PCB ×1 + 下阵列 PCB ×1**。

- 上下对称：每板 `8×8 = 64` 发射 NU40C10T、四角 `4` 接收器；整机 **128T + 8R**；接收订货后缀需要正式资料核验。
- 中央板：单颗 **AD7606C-16 8 通道同步采样**；三颗 TMP117（中央/上/下）；现有监测 IC、外部 USB-C/供电、J10/J11 接 AX7020。保留 FPGA 已有 IO/协议合约；若跨板 IO 不足不得私自改 RTL 合约。
- **四电源域**：AX7020 原独立电源；中央 PCB **独立 USB-C 5V/3A 候选**；上下阵列**各自独立 12V 适配器**，两侧插座计划为 5.5×2.5mm DC barrel（中心正负极按最新接口决定校验）。不得再沿用旧的“中央板从 AX7020 接口取主功率”“阵列采用 XT30”而不标冲突；不得由 AX7020 IO 提供发射功率、不得跨电源域倒灌。
- 相阵结构：每板 TX 64 路，现候选为 `TC4427A 32 颗/板`（每颗双输出）及 `SN74LVC595A 16 颗/板`；**这只是候选拓扑**，能否驱动 64 个声学负载要核算。
- 40kHz 为名义工作频率，换能器公差按可核数据表；演示物为**直径 2–5mm EPS 小球**。几何基线使用仓库最新用户批准值并显式记录证据；**严禁沿用已被覆盖的 12mm 阵列间距**（既有 PCB 审查资料候选标称声学发射面距 100mm、调节 90–115mm，须复核）。
- 接口：核对 J10/J11 80 个触点、其中既有候选 68 PL IO 与控制/ADC/温度/故障分配；检查实际 Bank VCCO、速度等级、OE/RESET、断电 Ioff、上电顺序、独立安全关断及 66MHz 数据/时钟传播时间，不能把候选 XDC 当作可烧录生产约束。

## 4. 核心设计审查顺序：先电源和驱动，再 ADC/RX，最后全量 R/C/L

### Gate A — 发射驱动与总功耗（P0）

**必须回答**：TC4427A 是双路 MOSFET 门驱动器，直接驱动 40kHz 压电换能器时，在本项目 12V 单端波形、负载电容/谐振与 128 路并行下，是否满足电流、频率、输入阈值、输出电压、驱动回灌、散热、EMI、安全保护？检查是否需要输出限流/阻尼/过流抑制，驱动输出禁止悬空、双边恢复及高电流地返回；默认关闭能否由硬件实现。比较单端 0–12V 与差分/半桥/全桥的**真实换能器端电压波形**，不得把 Vp-p、峰值和供电值混用，不得无用户审批换成全桥或 >12V 方案。

计算最少包括（在未知条件下给变量区间而非假数）：
- 由有来源的换能器标称静电电容 `C0`（先考虑 2.2nF、±20% 假设并标出处）与频率 `f`、波形摆幅 `ΔV` 计算保守的**理想电容动态能量数量级**，说明 `P ≈ C·(ΔV)^2·f` 的前提、充放电路径和上/下界，不可直接当作电源适配器总功率或声学辐射功率；
- 通道动态负载平均/峰值、驱动自身静态功耗及开关损耗、开关沿和串阻、电路实际 RMS/热、同时驱动 1/16/64/128 路占空的场景；
- 驱动额定瞬时峰值电流与**连续热预算区别**，输出极性、二极管/感性电流、供电旁路和地弹；
- 12V 供电 3.34A（约40W）与 5A（60W）方案逐板峰值、平均负载、裕量（20% 最低目标、30% 建议目标）、电源开机浪涌、线缆压降、DC 插座允许连续电流、输入 eFuse 限流和散热的一致性。总电流应基于完整实际驱动和辅助负载实算，不能先认定 40W/60W 足够。

**通过条件**：提出 `候选拓扑 A / 备选拓扑 B / 推荐方案`，每种必须列负载、功耗、失效风险、可用证据与验证方式，含必须做的低风险示波器/电流实测点；没有物料参数则明确 HOLD，不要强行量产结论。

### Gate B — 四电源域、12V 功率关断与 TPS3851（P0）

绘制各电源轨的输入/输出树：外置 5V 中央板，独立上下 12V，各阵列转换出的 5V/3.3V/模拟轨，FPGA Bank IO 兼容。每条轨给最小/典型/最大负载、额定纹波、电源时序与热裕度。核查 Type-C 只取 5V 时所需 CC/Rd/ESD/浪涌/过流/连接器供电能力；现有 STUSB4500L 等候选是必需、冗余还是协议不匹配须用原厂资料证明（不能以“能插上”代表 5V/3A 一定被保证）。

**重点：TPS3851H33EDRBR ×2**
- 对照 TI **完整精确后缀**、3.3V 欠压检测门槛、RESET/WDO 两个开漏输出逻辑、WDI **下降沿触发**、MR、SET1、CWD、复位延时、最低 POR 区域、看门狗故障恢复行为。
- 原厂资料指出 VDD 允许 **1.6–6.5V**；不能把 12V 接到 VDD，也不能声称其直接保护 12V 支路。若需监测 12V，另用合适的 UVLO/eFuse/比较器分压方案，明确拓扑和门限迟滞。
- 必须给定 **WDI 心跳来源**（真实 FPGA 状态机推进或独立可观测条件），不得由即使系统卡死仍自由翻转的时钟冒充心跳；给出正常最大喂狗间隔、首次启动窗口、故障条件、看门狗动作时序。
- 参考 TI 官方 `TPS3851` Rev.B：`RESET` 和 `WDO` 外部上拉允许 **1kΩ–100kΩ**，建议去耦 **0.1µF**；CWD 由电容或开路/经 10kΩ 上拉设定；若用可调电容，必须按 TI 公式和容差计算（不是自行拟合）。据 TI 表格，CWD 悬空的标称看门狗约 1.6s，经 10kΩ 上拉约 200ms（具体使用需核验 SET1 与时序状态）；不因这里列出示例值就直接定型。
- **WDO 不是默认锁存的永久断电信号**；需提出安全故障锁存、物理 kill/切断 12V 驱动能量、故障清除和人工恢复机制。功率 MOSFET/负载开关及其默认状态需要单独设计，OE 不得充当唯一安全屏障。监控芯片失电、逻辑未上电、线缆断开、心跳卡死、FPGA 异常和电源反接时都必须为默认禁止输出。
- 检查现有 TPS26631 eFuse 限流设定和 12V 适配器 3.34A/5A 方案是否冲突，TVS 最大钳位电压与后级 abs max 是否矛盾；过压/反接/热故障/短路的联锁优先级和复位时序明确写出。

绘出有向故障矩阵：`FAULT source → 硬件判定 → 锁存 → 物理功率禁止 → FPGA readback → 允许重启条件`；给出最坏情况关断延迟估计，指出额外元件需求。若无法证明**不依赖软件**的断电保障，Gate B `REVISE`。

### Gate C — DC/DC、LDO 与无源件真实计算（P0）

对每一条 Buck、LDO、电源输入和滤波网络做参数计算：

- **Buck**：按所用芯片原厂设计公式计算 `L`、`ΔIL`、`IL,peak`、`IL,rms`、`Isat`、`Irms`、DCR、温升、输出/输入陶瓷电容有效容值、DC 偏压降额、ESR 纹波、瞬态；对每个电源轨记录 `Vin(min/typ/max)`, `Vout`, `Iout(max)`, `fsw`, `η`, `ΔIL/Iout`, `ΔVout`, `Ta`, `Tj`。**不得直接以旧 BOM 6.8µH ≥5A 作为普适正确答案**；TPS54202 单芯片额定仅 2A，不能因电感标 5A 就认为降压级能输出 5A。
- **反馈电阻**：按原厂 `VREF`、输入偏置电流、FB 节点干扰、补偿网络算上下臂阻值并检查工作点/误差；选择常见 E24/E96 标称值后反算误差。对 EN/UVLO 分压给阈值与回差误差带。
- **LDO**：压差、最大热耗 `P=(Vin−Vout)·I`、铜皮散热和温升，供电时序/输入输出有效电容、陶瓷 ESR 稳定性与 PSRR/高频残留；原厂要求与候选值发生矛盾时以原厂为准。
- **储能/旁路**：12V 功率母线输入 bulk 电容、每颗 TC4427A 的本地 100nF/数 µF 是否足够应由开关峰值电流、供电轨允许瞬态跌落和回路寄生、电容 ESR/ESL 决定；ADC AVCC/VDRIVE/REGCAP/REFCAP、运放基准和数字控制芯片各自核对原厂就近去耦。不得把“302 颗电容”直接当成应有数量。
- **电源安全**：保险/自恢复保险、TVS、反向保护 MOS、浪涌限制、eFuse 检测/设定电阻、RC 延时、电源泄放/上电默认下拉、电流采样的功耗/精度/Kelvin 采样；按峰值与故障能量评估，而非单凭工作电压。
- **贴片封装与额定**：电阻至少列功率、脉冲能力、温漂及推荐 0603/0805/1206 或更大；普通 MLCC 优先 X7R/X5R（带偏压下的有效容量），精密时间/参考滤波优先 C0G/NP0；电感优先屏蔽 SMD 功率电感并记录饱和/温升/DCR。对于 12V 输入的陶瓷件，验证电压额定和实际工作偏置后提出有数据支撑的电压等级；不能习惯性把 16V MLCC 当有充分裕量。

每项无源件必须至少提供：`板别 / 功能 / 节点 / 元件类型 / 理论公式 / 代入参数来源 / 计算过程 / 理论值 / 选定标准值 / 容差及降额 / 封装建议 / 最坏情况 / 待实测量 / 证据 / 状态`。不同位置参数不同时**不得仅因为同为 100nF 就聚合**；理论值如缺乏边界输入则明确缺口，不允许用虚假的 1% 精度掩盖前提不确定。

### Gate D — 接收链路与 AD7606C-16（P0/P1）

- 8 个 RX 传感器的阻抗/共振特性及四角布置、发射器 40kHz 泄漏、前端最大接收电压和静电/上电故障情形需按可信资料/保守假设分析。
- 4 RX/板 → OPA4192 及可能的前端开关/限幅/滤波 → 中央 ADC 的完整电压余量、输出驱动、电缆长度与阻抗、偏置和输出保护；确认 `OPA4192×4` 的通道配置而不是把封装颗数误当通道数。
- **AD7606C-16 的 25kHz/220kHz 两种带宽区别**：40kHz 被 25kHz 模式衰减，必须核对 220kHz 模式的软件配置/初始化/上电默认与实读回。ADC 5V AVCC、VDRIVE 逻辑电平、并/串接口引脚、四路 DOUT、输入配置、参考去耦、采样触发与 8 路同步相位误差；要求列 ADC 输入 40kHz 采样与数字吞吐时序裕度。
- 对每路 RX AFE 的 R/C：根据 `40kHz` 目标、必要通带、ADC 采样率、滤波阶数、噪声和电缆寄生，从 transfer function 推导 `fc` / Q / gain / 抗混叠 / 保护电阻，并检验最坏的相位偏移对多通道自校准的影响。`fc=1/(2πRC)` 仅适用于对应的一阶网络，不得把它当任意多级反馈滤波的完整答案；必须给 Bode / AC 响应或手工传递函数。
- 数字 66MHz 高速时序、595 锁存/移位/OE 和跨板 3.3V 电平转换、对地回路和布线/线束的传播延时、串阻阻尼、上拉/下拉电阻、I2C 总线电容及上拉强度都需有依据，不可机械复用固定阻值。

### Gate E — 可靠性、机械与生产可落地性（P1）

- 三板机械安装空间、100mm 候选可调面距、10×10 虚拟网格与背面非阵列区器件排布；四角 RX 声学遮挡、TH 通孔焊接与驱动高密度、散热风道、边沿开关信号对接收噪声的耦合。
- 电源与信号接口的物理极性/键控/拔插顺序、地线回路、连接器额定电流及载流铜厚；固定点与绝缘间距，PCB 层数建议及成本对比。
- 可测性：每一重要电源/故障/心跳/相位输出/ADC SYNC 都要有测试点或可抓取点，支持分板低风险验收。
- 失效注入测试计划：12V 短路、3.3V 欠压、逻辑有电功率无电/功率有电逻辑无电、FPGA 未启动、接收前端过驱、线束反插/断线、WATCHDOG 停止、热故障等。仅制定测试方案，不在未批准时执行会损坏设备的实验。

## 5. 工程计算要求及证据约束

1. 先建 `ASSUMPTIONS_AND_UNKNOWNS`：每个关键量归类 `原厂保证/原厂典型/已实测/从合约获取/工程假设/未知`，逐项给来源链接、文件页码、数据更新时间。
2. 所有计算都必须写 SI 单位、公式适用条件、代入值、结果，并做**worst-case**（最高 Vin、最低电容有效值、最大负载、最高环境温度、芯片阈值偏差、温漂等）。给出可复算的 Python 脚本/CSV/Markdown 表格，必要时 LTspice/ngspice 简模可辅助，但**仿真 ≠ 真机测量**。
3. 数据缺失时先推导为变量函数或区间、生成 `DATA_REQUIRED`，不能随意把估计值标成确定数据。不能无来源写声功率、板端实际电耗、稳态悬浮力。
4. 比较现 BOM 原有 R/C/L 与重算方案，逐项标 `KEEP / CHANGE / ADD / DELETE / DUPLICATE_SUSPECT / BLOCKED`；识别 0Ω 条目和“驱动下拉电阻 TBD”是否重复，自动交叉位号，不得重复计算。
5. 能写计算工具但不修改正式 FPGA RTL/PS/PL、生产 XDC、硬件已批准接口与项目版本。任何建议改变现有核心时序、阵列几何、全系统数据协议或 3 板结构必须先上报 `DECISION_REQUEST`。
6. 禁止用“ERC 0 error”替代设计审核：现在无正式可用原理图，不得宣称 ERC 已验证；如有条件制作**功能级**原理图或 SPICE 块模型可作为候选证据，不能直接生成生产 Gerber/钻孔/下单文件。

## 6. 三阶段执行与门禁（严格按顺序）

**S2-A：调查和审图可行性**。检索公开参考、重建原有模块与跨板接口、电源树、找所有缺失的器件级电路、给 `ARCH_REVIEW`。P0 问题解决思路不足时，停下提交 BLOCKERS，不要进入 BOM 释放。

**S2-B：电源/驱动/安全定型候选**。从负载计算开始，对 TC4427 驱动与 TPS54202 Buck、TPS3851、eFuse、切断 MOS/电路逐一审查；把核心设计分成 **已证实 / 推荐待用户批准 / 必须验证 / 不可行**；形成完整 `POWER_AND_DRIVER_REVIEW`、`SAFETY_FAULT_MATRIX`、功耗热预算及至少两套合理备选。**若 P0 未闭环，标 REVISE。**

**S2-C：R/C/L 规格候选与 BOM 差分**。仅在 S2-B 工程方案论证足够后，把所有电路扩展到阻容感计算。输出 `PASSIVE_CALC_REGISTER` 和 `BOM_DELTA_DRAFT`，保留未定 MPN，用规格范围+封装形式表达采购条件。**本轮不批准最终 BOM**；只有在电源驱动与关键保护经用户/主对话审核接受后，下一次独立任务才启动 `BOM_RELEASE_CANDIDATE`。

## 8. 严格停止条件 / 汇报格式

- 任一 P0 缺原厂电气限制或无法证明硬件默认关断，结果写 `REVISE`，不输出“可制造”结论。
- 当 P0 的拓扑已被充分证明，但缺实测或真实 PCB/ERC，最多给 `ACCEPT WITH LIMITATIONS`；尚无板级证据时不能称 `ACCEPT FOR FABRICATION`。
- 保留所有工作在 **v5**、PCB 专项独立候选分支；不自动 merge、不进行 PCB 制造/采购、不修改永久启动数据；不得自作主张改变 NU40C、AX7020、ADC 等已批准核心器件。
- 最后回复用户固定给出：**① 结论 ② 已证实的核心电路 ③ 最危险的 5 项问题 ④ 推荐电源/驱动方案和理论依据 ⑤ TPS3851×2 替换是否功能完备 ⑥ 各类 R/C/L 新增/修改数量及可追溯计算 ⑦ 最新 BOM 是否仍 HOLD ⑧ 下一步待用户批准的具体决策 ⑨ 文件路径/commit/证据哈希**。
- 若确认方案需额外芯片，不违背本轮“合并替代”指令：区分**两颗 TPS3851 占位合并结果**与**独立功能需要的保护器件新增**，单独提出必要性；不能为了维持原先芯片数量而牺牲安全性。

**立即从 S2-A 开始执行，按实际证据推进；无充分资料时如实停在门禁点。最终交付所有审查证据给主对话窗口验收后，才进入正式原理图与 BOM Release 的下一阶段。**
