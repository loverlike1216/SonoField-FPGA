# 63/68 GPIO 与信号完整性审查

来源为本地V3.0手册35页，J10表在29–30页，J11表在31–33页。
80触点=68GPIO+6GND+2个5V+4个3.3V。本轮两个开发板5V和四个3.3V
接点全部NC。上下共32DATA、18控制状态、10ADC、2I2C、1ESTOP状态，
合计63GPIO、5备用。Bank34共30GPIO，Bank35共38GPIO；Bank35电压可改，
默认3.3V文字不证明实际电压。手册与Vivado封装核对不能证明实板导通。

`config/SIGNAL_CONTRACT.json`是最新候选。原生可部署板级wrapper未完成。
237条连接合同逐点记录直接端口、共享端口扇出和未接功能。
SRCLK/RCLK/heartbeat是共同逻辑端口，分到两阵列要匹配缓冲、回流和偏斜。
OE_N为低有效输出使能：现有output_disable高时使能被禁止，电平一致，不反相。
ADC RESET为高有效，AD7606C-16第11脚接ADC_RESET，不能照抄_RESET_N。
阵列RESET_N/SYNC尚无本顶层对应端口；I2C控制器未接本顶层；FAULT_N需
硬件聚合及health接口资格证明。eFuse启用请求与独立安全截止不能因为
63脚表未独立列出就被删除，具体端口/硬件组合在原生电路前保持OPEN。

外部时序每线需要以下量：FPGA tCO min/max，板上33Ω及缓冲延迟min/max，
正反向线缆延迟、时钟数据偏斜、远端595setup/hold、PVT、抖动及上升/下降沿。
约66MHz周期15.152ns，半周期7.576ns。采用哪一边沿、是否源同步与相位调整
须以serializer实际波形和器件时序表核查。不能将半周期全部当有效裕量。

候选传播速度仅用于敏感度：5–7ns/m、长度0.1/0.2/0.5m对应0.5–3.5ns单程；
必须另加缓冲tPD、扇出负载和连接器/走线。没有合格的线长和tPD上下界，
不写虚假的set_input_delay/set_output_delay。完整旧OOC的161输入/148输出
延迟缺口和346REQP-1839警告仍需关闭。审查XDC首行主动error阻止误部署。

每阵列至少每组高速数据就近参考地、时钟单独回流；RX模拟屏蔽/回流不与
12V驱动脉冲共用回路。2×20/2×25排针和≤20cm排线仍是未验证候选，不能
声称支持66MHz。示波器检查：源/目的端SRCLK/DATA/RCLK、同步偏斜、振铃、
过冲、地弹、reset/blank/OE、局部掉电Ioff、连接顺序和所有相位并发。

I2C100kHz默认；TCA9548A0x70，0/1/2域分别中央/上/下，单域one-hot。
各域TMP117/INA226可同地址复用，但同域内必须不同地址。候选每域TMP117
0x48、INA2260x40，中央STUSB4500L地址另核，不跨域广播三颗同地址器件。
100kHz、400pF、3.3V、VOL0.4V、3mA假设给上拉约967–2951Ω，2.2kΩ
落在假设区间；这不是实际线缆C和sink电流测量。所有并联上拉须合并计算。
Mux当前选中的SDA被拉低时，软件不能通过堵塞的同一总线可靠发送关闭命令。
须独立RESET/监督/掉电隔离，63GPIO尚未分配专用reset/IRQ，不能宣称恢复已闭环。

ADC四DOUT数据量下界为32×800k=25.6MHz，128bit/样本=12.8MB/s。
115200/8N1理论净字节上限11520B/s，不能连续上传全部ADC样本。
预算模型900ns BUSY/33MHz SCLK/80ns额外时间仅是假设串行不重叠例，
不代表现有已通过设备模型的流水采集失败。真实性能须逐项证实读转换重叠、
时序窗口、量程/OS/CRC配置和XSim/Icarus模型与真实器件的一致性。
