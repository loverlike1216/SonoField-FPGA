# 10 mm 换能器的辐射面坐标与可调机械边界

本文件执行用户 2026-09-19 的明确几何修改，替代之前 16 mm / 18 mm 点距 / 72 路示例。
当前设计为上下两个平面阵列，各 8×8，共 128 个发射器。凹面仿真仅保留为比较，不改变本机械定义。

## 坐标定义（mm）

Transducer Coordinate = **Radiating Surface Center**。原点 (0,0,0) 是上下全部辐射面中心的几何中心。
全局 +Z 指向上阵列，+X/+Y 在两面共用；上下对应的同编号发射器具有相同 x/y。

对 `row,col = 0..7`：

```text
local_index = 8*row + col
x = (col - 3.5) * 12
y = (row - 3.5) * 12
UPPER_TX_local_index = (x, y, +g/2), normal = (0,0,-1), RTL = local_index
LOWER_TX_local_index = (x, y, -g/2), normal = (0,0,+1), RTL = 64 + local_index
g = 上下辐射面到辐射面的实际间距
```

x、y 各为 `[-42,-30,-18,-6,6,18,30,42]`。偶数 8×8 阵列在 x=0/y=0 没有阵元中心，
这不改变系统原点位于 (0,0,0)。阵列的每个坐标均为辐射面中心，不是 PCB 中面或引脚根部。

| 辐射面间距 g | 上辐射面 z | 下辐射面 z |
|---:|---:|---:|
| 90 | +45 | -45 |
| 95 | +47.5 | -47.5 |
| 100（默认） | +50 | -50 |
| 105 | +52.5 | -52.5 |
| 110 | +55 | -55 |
| 115 | +57.5 | -57.5 |

## 机械尺寸与调节余量

- 辐射面中心跨度：7×12 = **84 mm**，X/Y 相同。
- 直径 10 mm 时名义器件外包络：84+10 = **94×94 mm**。
- 相邻外壳名义净间隙：12−5−5 = **2 mm**，不是半径之间再额外增加 2 mm。
- 全程面间距调节量：115−90 = **25 mm**；若两面关于原点同步对称移动，每面全行程 **12.5 mm**。
- 相对默认 100 mm：每面向中心可走 5 mm，向外可走 7.5 mm。机构需覆盖两个端点，并在行程外
  留出装配、止挡和锁紧空间；这些额外机械余量要由实际结构决定，当前不擅自指定螺杆/滑槽尺寸。
- 94×94 mm 是器件名义外包络，**不是已选 PCB 外形尺寸**。支撑孔、固定边距、电缆出口尚未冻结。

单面中心的逐点坐标、上下全局编号和法向量见 `geometry_10mm/coordinates_nominal.csv/json`。
同目录附 90/95/100/105/110/115 mm 各间距坐标及 STANDING_WAVE、FOCUS 相位图。
间距变化会改变相对传播相位，应按实际 g 重算整张图，然后原子 COMMIT。
系统尚无测距传感器或电动调距闭环；软件设置值必须来自实际机械测量。

## PCB、壳体与辐射面的区别

图片标称壳体高 7 mm。如果壳体从辐射面向背面延伸，其名义背面在默认间距下约为 z=±57 mm。
这只是壳体几何示意。PCB 到辐射面的有效高度包含实际器件高度、辐射面位置和安装支承/悬空量，
不能仅凭照片认定 PCB 间距为 114 mm。若实测上下安装有效高度为 h_upper、h_lower：

```text
PCB_upper_z = +g/2 + h_upper
PCB_lower_z = -g/2 - h_lower
PCB_plane_gap = g + h_upper + h_lower
```

h_upper、h_lower 未测量，因此配置和导出 JSON 的 PCB 平面/间距均为 null。
图片中的 ±0.5..1 mm 手工误差不是生产公差。实际 2 mm 间隙还受直径、放置误差和倾斜影响。

## 视图与极性

坐标表统一使用全局坐标。从上板背面或下板背面观察，图像可能镜像，但不得因此重新编号 RTL 通道。
加工视图需要单独的 view-to-global 变换。发射面朝向中心；图片 '+' 标记是供应商电气标记，
不替代示波器声学相位/极性校准。引脚朝外，PCB/驱动连接位于各辐射面背后。

本文件与 SVG/PNG 是名义布置资料，不是孔径、公差、绝缘或 Gerber 生产文件。
